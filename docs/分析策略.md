### 维度一：热度与规模（“热不热”）

| 指标                  | 计算方法                                     | 它能告诉你什么                                         |
| --------------------- | -------------------------------------------- | ------------------------------------------------------ |
| **1. 弹幕密度**       | 每秒/每10秒的弹幕条数                        | 热度的最基础指标，定位高潮候选点                       |
| **2. 爆发速率**       | 密度的斜率，即连续两个时间窗口之间的密度差值 | 瞬间惊吓/神操作（尖峰）vs 逐渐升温的节奏（缓坡）       |
| **3. 沉默用户激活率** | 高潮时段发言者中，此前整场发言≤2次的人占比   | 出圈程度。高占比 = 潜水的都被炸出来了，真正的大高潮    |
| **4. 弹幕长度分布**   | 短弹幕(≤5字) vs 长弹幕(>15字) 的比例变化     | 短弹幕激增 = 情绪宣泄；长弹幕激增 = 深度讨论或节奏争议 |

其中**沉默用户激活率**是重点指标。你只需先把每个用户ID在全场的总发言数算出来，给每个人打上“沉默/活跃/核心”的标签。高潮时刻一触发，看发言用户里谁在说话，就能立刻算出这个比例。它比等级更能反映真实影响力，因为很多高等级用户其实经常挂机，而一个只发了1条弹幕的0级路人开口，反而说明内容真的击穿了阈值。

---

### 维度二：用户行为与参与模式（“怎么热的”）

这是用行为来逆向刻画用户画像，替代缺失的等级/勋章数据。

| 指标                          | 计算方法                                                     | 它能告诉你什么                                               |
| ----------------------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| **5. 发言集中度（基尼系数）** | 统计每个用户在该时段的发言占比，计算基尼系数。0 = 完全均匀，1 = 完全由一人垄断 | 高集中度 = 少数人在刷屏/争吵/控场；低集中度 = 人人都在表达，群体共鸣 |
| **6. 用户重合度（相邻时段）** | 比较当前时段和前一个时段的发言用户集合，计算交集占比         | 低重合度 = 新事件、新人群入场；高重合度 = 同一事件的延续讨论 |
| **7. 用户生命周期聚类**       | 将用户按“首次出现时间”和“最后出现时间”分组：<br>- **瞬时用户**：只在该高潮窗口内出现<br>- **持续用户**：在高潮前就已活跃，并持续到高潮后<br>- **转化用户**：高潮前沉默，高潮时被激活，高潮后留下来继续发言 | 瞬时用户多 = 热点引来的围观路人；转化用户多 = 这次高潮留住了人，有长期价值 |
| **8. 回锅用户比例**           | 统计该时段发言的用户中，有多少人在本次直播的前期已经活跃过，中间长时间沉默，现在又回来发言 | 说明事件有“召回效应”。比如前期看了离开的观众，被某个名场面吸引回来 |

发言集中度和用户生命周期这两个指标配合使用时威力最大。比如你发现一个弹幕密度高峰，但基尼系数极高——说明弹幕是被两三个人刷上去的，很可能是直播间里的两个观众在吵架，旁边几百人都在围观但不说话。这种场景如果只看密度会被误判为高潮，实际上它是“假热度”。

### 维度三：情感与语义（“为什么热”）

这是整个指标体系里最核心的维度，密度只能告诉你“热了”，语义才能解释“为什么热”。

| 指标                             | 计算方法                                                     | 它能告诉你什么                                               |
| -------------------------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| **9. 细粒度情感密度**            | 预设多个情感词库（惊叹、喜悦、愤怒、悲伤、疑惑、节奏指挥），计算每类词每秒的密度 | 画出多条情感曲线，精准定位高潮性质。例如密度波峰和“愤怒”词波峰完全重合，这就是一个节奏爆发点 |
| **10. 弹幕语义主题数**           | 将该时段的弹幕用大模型接口做主题聚类，看自动聚出几个话题簇   | 观众在讨论什么？是在说主播操作，还是在议论路人，还是在刷一个梗？主题越集中，高潮越聚焦 |
| **11. 独特词突增（TF-IDF）**     | 对比高潮时段与基准时段（开场30分钟）的词频，自动挖掘此时突然涌现的特殊词汇 | 发现你预设词库漏掉的新梗、黑话、外号。比如某主播打出下饭操作，弹幕里冒出只有老粉才懂的专有名词，这个词在其他时段从未出现 |
| **12. 弹幕复制率（刷队形指数）** | 连续N条弹幕中，完全相同或编辑距离<2的弹幕占比                | 刷队形是直播文化中最强烈的集体共鸣仪式。“全体起立”、“一波了”这类队形刷屏 = 仪式化狂欢 |

独特词突增（TF-IDF）值得单独强调。预置词库永远有滞后性，不可能覆盖所有主播的梗和当天的新事件。TF-IDF能帮你自动发现“此时此地”的关键词，比如某场直播中突然大量出现“红帽子”这个词——你回头一看画面，原来是一个戴红帽子的路人做了某件事。这个词可能只在这个直播间的这5分钟里才有意义，但它恰恰是高潮的语义锚点。

---

### 维度四：互动与关系（“谁和谁在互动”）

| 指标                 | 计算方法                                                     | 它能告诉你什么                                               |
| -------------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| **13. 对话网络密度** | 通过@关系、以及弹幕内容的文本相似度构建用户之间的回复网络，计算网络密度 | 高密度 = 用户之间在吵架/讨论；低密度 = 所有人都在单向对主播喊话 |
| **14. 观点极化度**   | 将弹幕按情感正负分组，计算正负两派的比例差。差值越小，极化越严重 | 出现重大节奏/争议时，正反两派比例越接近（如55%对45%），说明争吵越激烈 |
| **15. 意见领袖突现** | 检测在该时段突然获得大量回复或跟随发言的核心用户             | 识别谁是节奏的发起者。一个高潮可能由一条弹幕引爆，找到这条弹幕就能复现高潮的传播链 |

观点极化度是识别“节奏型高潮”的关键。举个例子：一个弹幕密度高峰，情感比例是95%正向、5%负向，这是众星捧月式的操作秀；但如果比例是52%正向、48%负向，那几乎可以断定是一场舆论撕裂的争议现场——两种高峰的外在热度可能完全一样，但直播效果和后续影响截然不同。

---

### 维度五：时间演化与价值（“热了多久，效果如何”）

| 指标                 | 计算方法                                                     | 它能告诉你什么                                               |
| -------------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| **16. 高潮持续时间** | 定义高潮区间（密度 > 均值 + 2个标准差），计算从突破阈值到回落的时间跨度 | 区分尖峰型（1分钟内）、高原型（持续5分钟以上）、多峰型（反复冲高） |
| **17. 高潮衰减模式** | 计算高潮结束后的弹幕密度衰减曲线，是指数级骤降，还是平缓回落 | 骤降 = 一次性的情绪宣泄；平缓回落 = 事件引发持续讨论，用户还在回味 |
| **18. 用户留存转化** | 在高潮时段首次发言或重新激活的沉默用户，在10分钟、30分钟后是否还在发言 | 衡量高潮的“带货力”。能把路人留下来，比单纯的热度更有价值     |
| **19. 事件关联引爆** | 一个高潮发生后，是否在短时间内引发了另一个独立的高潮         | 识别“高潮链”。比如主播一个下饭操作（高潮A），引发弹幕群嘲，群嘲又引发房管封人（高潮B），封人又引发更大节奏（高潮C） |

---

### 最终实践建议：用这套指标的一个完整分析流程

1.  **先用密度和爆发速率**扫一遍全场，标记所有候选高潮点。
2.  **对每个候选点，一键跑批**：沉默用户激活率、情感密度、发言集中度、独特词突增这四个指标。这四个指标的组合已经能区分90%的高潮类型。
3.  **类型判定**：
    -   沉默用户激活率高 + 短弹幕多 + 情感高度统一（如惊叹词占比70%以上）→ **出圈式神操作/名场面**
    -   发言集中度低 + 长弹幕多 + 观点极化度趋向50/50 → **争议性节奏事件**
    -   弹幕复制率高 + 情感统一为喜悦 → **粉丝集体狂欢/仪式时刻**
    -   用户重合度极低 + 独特词突增明显 → **新话题引爆点，可能来自外部事件或画面新信息**
4.  **最后看时间演化**：判断这个高潮是昙花一现，还是留住了人、引发了连锁反应。

## 直播弹幕高潮分析指标体系（全19项）

---

### 指标1：弹幕密度

**所属维度**：热度与规模

**核心问题**：热不热？

**定义**：单位时间窗口内的弹幕数量，是所有后续指标的地基。

**计算公式**：
```
设时间窗口为 W 秒，时间点 t 的密度为：
D(t) = count(弹幕时间戳 ∈ [t, t+W))
```

**参数建议**：
- 窗口大小 W：推荐 **10秒**。1秒太碎噪声大，30秒太粗模糊边界，10秒在实践中最为平衡
- 滑动步长：**1秒**，即每秒计算一次过去10秒内的弹幕数，实现高精度扫描

**输出**：一条时间序列 `D[0], D[1], D[2], ...`，每秒一个值

**阈值经验**：
- 整场直播的密度均值 μ_D 和标准差 σ_D 是后续所有阈值判定的基准
- 高潮候选：`D(t) > μ_D + 2σ_D`
- 强高潮候选：`D(t) > μ_D + 3σ_D`

**注意事项**：
- 直播开场和结尾的弹幕密度通常有独立的波动模式（开场寒暄、结尾告别刷屏），可以分段计算基线
- 如果存在弹幕抽奖/红包环节，会出现机器刷屏造成的假峰，需要通过弹幕内容重复度做过滤

---

### 指标2：爆发速率

**所属维度**：热度与规模

**核心问题**：怎么热起来的？瞬间炸开还是慢慢升温？

**定义**：弹幕密度的一阶差分，衡量热度爬升的陡峭程度。

**计算公式**：
```
原始：S(t) = D(t) - D(t-1)
```

**平滑处理（强烈推荐）**：原始差分噪声很大，先做3点移动平均再计算差值：
```
D_smooth(t) = (D(t-1) + D(t) + D(t+1)) / 3
S(t) = D_smooth(t) - D_smooth(t-1)
```

**补充指标——相对爆发速率**：
```
S_rel(t) = D(t) / max(D(t-1), 1)
```
这个指标能捕捉低基数区的突然引爆——比如从前一秒的5条跳到50条，S_rel=10倍，绝对差值只有45但相对变化极其剧烈。

**阈值经验**：
- 计算整场 S(t) 的标准差 σ_S
- **爆发候选点**：`S(t) > 3 × σ_S`
- **强爆发**：`S(t) > 5 × σ_S` 且 `S_rel(t) > 5`

**形态判断**：
| S(t) 特征      | 含义                                         |
| -------------- | -------------------------------------------- |
| 极高但瞬间回落 | 尖峰型事件（惊吓、瞬发笑点）                 |
| 中等但持续为正 | 渐进升温型（逐渐展开的冲突或剧情）           |
| 剧烈正负交替   | 弹幕在反复“炸锅-平复-炸锅”，通常是多波次节奏 |

---

### 指标3：沉默用户激活率

**所属维度**：热度与规模

**核心问题**：热出圈了吗？潜水的人被炸出来了吗？

**定义**：在当前时间窗口内发言的用户中，全场发言极少（≤2次）的“沉默用户”所占的比例。

**计算步骤**：

**第一步：全场用户分类**
```
遍历整场直播的所有弹幕，统计每个用户的总发言次数
设阈值 K=2：
- 总发言次数 ≤ 2  → 沉默用户
- 总发言次数 > 2  → 活跃用户
```

**第二步：滑动窗口统计**
```
对于时间点 t 的窗口 [t, t+W)，W=10秒：
激活率(t) = 该窗口内发言的沉默用户数 / 该窗口内发言的总用户数
```

**阈值经验**：
| 激活率  | 含义                                                 |
| ------- | ---------------------------------------------------- |
| 20%-40% | 正常水平，大部分弹幕由活跃用户贡献                   |
| 40%-60% | 轻度出圈，内容开始触动沉默群体                       |
| 60%-80% | 明显出圈，路人纷纷下场                               |
| > 80%   | 确定无疑的“出圈级”高潮，几乎所有沉默用户都被炸出来了 |

**注意事项**：
- 直播前5分钟所有用户都是“新人”，该指标在此区间失真，建议跳过或设置5分钟观察期——只有开场5分钟后的发言才将用户计入沉默池
- 需要和弹幕密度联合使用：密度高且激活率高 = 真正的大高潮；密度高但激活率低 = 核心粉丝自嗨

### 指标4：弹幕长度分布

**所属维度**：热度与规模

**核心问题**：观众在宣泄情绪还是在深度讨论？

**定义**：时间窗口内短弹幕（≤5字）和长弹幕（>15字）各自占比的动态变化。

**计算公式**：
```
短弹幕占比(t) = count(窗口内弹幕字数 ≤ 5) / 窗口总弹幕数
长弹幕占比(t) = count(窗口内弹幕字数 > 15) / 窗口总弹幕数
中弹幕占比(t) = 1 - 短弹幕占比(t) - 长弹幕占比(t)
```

**阈值与含义**：
| 特征                 | 含义                   | 典型场景                         |
| -------------------- | ---------------------- | -------------------------------- |
| 短弹幕占比突升 > 70% | 情绪宣泄，快速刷屏     | 神操作、惊吓、笑点爆发           |
| 长弹幕占比突升 > 30% | 深度讨论或解释性发言   | 节奏分析、争议辩论、户外路线指挥 |
| 长短弹幕同时飙升     | 事件同时触发情绪和讨论 | 重大争议，有人刷情绪有人讲道理   |

**与指标1的联动**：密度高但几乎全是短弹幕，说明是瞬发情绪释放，衰减通常也快（对应指标17骤降型）；密度高且长弹幕占比显著上升，预示这个高潮可能会持续较长时间。

---

### 指标5：发言集中度（基尼系数）

**所属维度**：用户行为与参与模式

**核心问题**：是全民参与还是少数人在刷屏？

**定义**：衡量时间窗口内弹幕在用户间的分布均匀程度。高集中度 = 少数人垄断发言，低集中度 = 人人都在说话。

**计算公式**（工程简化版——Top-K占比法）：

与其计算完整基尼系数，工程上使用更直观的近似指标：
```
发言集中度 = 窗口内发言最多的前3个用户的弹幕数之和 / 窗口总弹幕数
```
该近似指标在绝大多数场景下与完整基尼系数高度正相关（实测r>0.9），且计算成本极低。

完整基尼系数（如需更精确）：
```
1. 统计每个用户的发言数，按升序排列：x₁, x₂, ..., xₙ
2. 总发言数 S = Σxᵢ
3. 基尼系数 G = (2 × Σ(i × xᵢ)) / (n × S) - (n+1)/n
   其中 i 是用户按发言量升序排列后的序号（从1开始）
```

**阈值经验**（以Top-3占比为准）：
| Top-3占比 | 含义                                     |
| --------- | ---------------------------------------- |
| < 20%     | 高度分散，人人都在表达，群体共鸣型       |
| 20%-40%   | 正常互动分布                             |
| 40%-60%   | 出现明显的刷屏个体                       |
| > 60%     | 少数人垄断弹幕区，可能是争吵、刷梗或控场 |

**与指标1的组合判断**：
- 密度高 + 集中度低 → 真正的群体高潮
- 密度高 + 集中度高 → “假热度”，弹幕量被几个人撑起来，多数观众在围观

### 指标6：用户重合度

**所属维度**：用户行为与参与模式

**核心问题**：是同一个话题在延续，还是切入了全新事件？

**定义**：相邻两个时间窗口之间，发言用户集合的重叠程度。

**计算公式**（Jaccard相似度）：
```
设窗口A的用户集合为 U_A，窗口B的用户集合为 U_B：
用户重合度 = |U_A ∩ U_B| / |U_A ∪ U_B|
```
取值 [0, 1]，0=完全换了一批人，1=完全相同的一批人。

**参数建议**：
- 窗口大小：**30秒**（太短用户数不足，太长模糊事件边界）
- 比较对象：相邻窗口（如第30-60秒 vs 第60-90秒）
- 如果计算资源允许，可以同时拉一条60秒窗口的曲线做平滑对照

**阈值经验**：
| 重合度  | 含义                                         |
| ------- | -------------------------------------------- |
| > 60%   | 用户群高度重叠，同一事件的延续讨论           |
| 30%-60% | 正常过渡，人群在自然更替                     |
| < 30%   | 用户群显著更替，极可能是一个**新事件的开始** |

**实战技巧**：当重合度突然跌破30%且新窗口密度开始爬升时，几乎可以确定是一次“事件切换”——旧话题的讨论者退场，全新人群涌入讨论新话题。这个切换点本身就是重要的内容结构标记。

### 指标7：用户生命周期聚类

**所属维度**：用户行为与参与模式

**核心问题**：来的人是看完就走，还是留下继续看？

**定义**：根据用户在整场直播中的首次和末次发言时间，将其划分为不同生命周期类型，然后统计高潮窗口中各类型的占比。

**分类标准**：
```
设高潮窗口为 [t_start, t_end]：

瞬时用户：首次发言 ∈ 高潮窗口，且末次发言 ∈ 高潮窗口
         （只在高潮时出现，高潮结束就消失）

持续用户：首次发言 < t_start - 5min，且末次发言 > t_end + 5min
         （高潮前就在，高潮后还在，是直播间的“原住民”）

转化用户：首次发言 ∈ [t_start - 2min, t_end]，且末次发言 > t_end + 10min
         （高潮前后被激活，而且留下来了）
```

**阈值与含义**：
| 瞬时用户占比 | 含义                                       |
| ------------ | ------------------------------------------ |
| > 50%        | 热点引来的围观路人，看完就走，留存价值低   |
| 30%-50%      | 有一定围观效应，但也有不少人留下           |
| < 30%        | 高潮主要由直播间原住民驱动，外部引流效果弱 |

**核心关注指标**：转化用户绝对数量。它直接衡量这次高潮“拉新且留住”的能力，比瞬时用户的绝对数量更有长期价值。

---

### 指标8：回锅用户比例

**所属维度**：用户行为与参与模式

**核心问题**：这个事件有没有把已经离开的老观众召回来？

**定义**：在当前高潮窗口中发言的用户里，那些在本次直播前期已活跃过、中间经历了长时间沉默（≥20分钟）、现在又重新发言的用户所占的比例。

**计算步骤**：
```
1. 定义“回锅用户”需同时满足：
   - 在直播前30分钟内至少发过1条弹幕（证明来过）
   - 在 t-20min 到 t-2min 之间零发言（证明离开过，2分钟缓冲避免把正常发言间隔误判为离开）
   - 在当前高潮窗口中重新发言（证明被召回）

2. 回锅用户比例 = 窗口内回锅用户数 / 窗口内总用户数
```

**阈值与含义**：
| 回锅用户比例 | 含义                                                         |
| ------------ | ------------------------------------------------------------ |
| < 5%         | 正常水平，少数老观众恰好回来                                 |
| 5%-15%       | 有明显的召回效应，事件在老观众群体中传播                     |
| > 15%        | 极强召回，事件可能在其他渠道（社交媒体、切片的传播）引发了回流 |

**实战价值**：回锅用户比例高的事件，通常是直播的“名场面”级别——它不仅在直播内引爆，还通过社交传播把已经流失的观众拉了回来。这类事件做成切片和二创的传播潜力最高。

### 指标9：细粒度情感密度

**所属维度**：情感与语义

**核心问题**：观众在用什么情绪讨论这件事？

**定义**：单位时间窗口内，各类情感词的出现密度。将情绪分为六类：惊叹、喜悦、愤怒、悲伤/感动、疑惑、节奏/指挥。

**情感词库（最小可用集合）**：

| 情感类别  | 种子词                                                       |
| --------- | ------------------------------------------------------------ |
| 惊叹      | 卧槽、我草、wc、牛逼、nb、我的天、啊？、？？？、不是吧、离谱、太强了、神仙 |
| 喜悦      | 哈哈、hhh、笑死、太搞了、可爱、爱了、好活、舒服了、nice、好耶 |
| 愤怒      | 恶心、恶心心、傻逼、sb、滚、滚啊、真下头、吐了、爬           |
| 悲伤/感动 | 泪目、破防了、哭了、刀、太刀了、respect、瑞思拜、敬礼、正能量、不容易 |
| 疑惑      | ？？？、啥情况、没看懂、剧本吧、真的假的、什么鬼、什么意思   |
| 节奏/指挥 | 冲了他、举报了、上啊、别去、别洗了、急了、他急了、典、孝、绷不住了 |

**计算公式**：
```
对于时间窗口 [t, t+W)，情感类别 E 的密度：
Emo_E(t) = count(窗口内命中类别E词库的弹幕条数) / W

注意：一条弹幕可能同时命中多个类别（如“哈哈哈牛逼”=喜悦+惊叹），各自计数，不互斥。
```

**归一化——情感占比**：
```
EmoRatio_E(t) = Emo_E(t) / Σ(所有类别 Emo(t))
```
用占比而非绝对值来判断主导情绪，避免密度基数差异的干扰。

**阈值与高潮定性**：
| 情感占比特征        | 定性结论          |
| ------------------- | ----------------- |
| 惊叹占比 > 50%      | 技术秀/神操作     |
| 喜悦占比 > 50%      | 搞笑/节目效果     |
| 愤怒+节奏占比 > 50% | 节奏/争议/冲突    |
| 悲伤/感动占比 > 40% | 情感暴击/感人时刻 |
| 疑惑占比 > 40%      | 突发事件/迷惑行为 |

**关于“？？？”和“啊？”的双重归类**：这两个词同时属于惊叹和疑惑词库。消歧逻辑为——如果同一窗口内喜悦+惊叹类词占比已经超过40%，则“？？？”倾向计入惊叹；如果窗口内无明显的正向情绪，则倾向计入疑惑。

### 指标10：弹幕语义主题数

**所属维度**：情感与语义

**核心问题**：讨论是聚焦还是发散？集中在什么话题上？

**定义**：时间窗口内弹幕语义聚类后的主题数量。主题越少越集中，高潮的内容指向性越明确。

**计算步骤**：

**第一步：弹幕向量化**
| 方案   | 做法                                                | 优点                   | 缺点           |
| ------ | --------------------------------------------------- | ---------------------- | -------------- |
| 轻量级 | 用中文预训练词向量对分词后取加权平均                | 离线可跑，零成本       | 短文本效果一般 |
| 推荐   | 调用大模型Embedding接口（如text-embedding-3-small） | 语义理解准，短文本友好 | 有API成本      |
| 高精度 | 大模型直接做短文本聚类并输出主题标签                | 直接可读，无需后处理   | 成本最高       |

**第二步：聚类确定主题数**
```
1. 对该窗口内的弹幕向量做K-Means聚类，K从1到10遍历
2. 用轮廓系数（Silhouette Score）确定最佳K值
3. 如果所有K的轮廓系数都<0.2，说明弹幕发散无结构，主题数标记为"发散"
```

**阈值与含义**：
| 主题数    | 含义                                               |
| --------- | -------------------------------------------------- |
| K=1-2     | 高度聚焦，所有人讨论同一两个话题 → 高潮指向明确    |
| K=3-4     | 有一定发散，但仍在可控范围                         |
| K≥5或发散 | 各说各的，弹幕密度高可能是多个小话题拼凑的“伪高潮” |

**实战用法**：用于高潮的语义标签命名。取高潮窗口弹幕，聚类后提取每个主题簇的TF-IDF关键词Top5，用最大簇的关键词给高潮命名（如“反杀操作”、“红帽子路人”、“封禁争议”）。

### 指标11：独特词突增（TF-IDF）

**所属维度**：情感与语义

**核心问题**：有没有新梗或突发事件关键词突然冒出来？

**定义**：在高潮时段突然大量出现、但在其他时段几乎看不到的词。完全不依赖预置词库，自动发现新事件的关键词。

**计算步骤**：

**第一步：文档切分**
```
推荐方案：按弹幕密度的波谷作为自然切分点
- 找到密度持续低于 μ_D - σ_D 的时间段作为"缝隙"
- 每两个缝隙之间作为一个独立"文档"
- 这样每个文档内部讨论的是同一个话题，TF-IDF语义更干净
```

**第二步：计算TF-IDF**
```
对于文档d中的词w：
TF(w, d) = 词w在文档d中的出现次数 / 文档d的总词数
IDF(w) = log(总文档数 / 包含词w的文档数 + 1)  （+1防除零）
TF-IDF(w, d) = TF(w, d) × IDF(w)
```

**第三步：提取高潮独特词**
```
对于高潮窗口对应的文档 d_high：
1. 计算d_high中每个词的TF-IDF
2. 过滤停用词和全程高频通用词
3. 取TF-IDF Top 10-20
```

**筛选阈值**：
- TF-IDF > 0.1
- 该词在其他文档中的TF-IDF均值 < 0.01（确保独特性）
- 在高潮窗口内出现次数 ≥ 3（过滤偶然噪声）

**实战价值**：预置词库永远有滞后性。TF-IDF能自动发现“此时此地”的特殊词——一个外号、一个地名、一个事件的简称，只在这场直播的这个时段有意义。结合指标9的情感标签，就能拼出“观众在愤怒地讨论XX”这样的完整叙事。

### 指标12：弹幕复制率（刷队形指数）

**所属维度**：情感与语义

**核心问题**：有没有形成集体仪式？观众是不是在刷同一句话？

**定义**：在时间窗口内，完全相同或高度相似的弹幕所占的比例。这是直播文化中最强烈的集体共鸣信号。

**计算步骤**：

**第一步：定义“相似”**
```
两条弹幕A和B判定为相似，满足任一：
条件1：去除首尾空格和标点后完全相等
条件2：编辑距离（Levenshtein）≤ 2
条件3：最长公共子序列长度 / max(len(A), len(B)) > 0.8
```

**第二步：复制链检测**
```
对于窗口内的弹幕按时间排序 m₁, m₂, ..., mₙ：
1. 从m₁开始，向后遍历，找到所有与m₁相似的弹幕，形成"复制链1"
2. 跳过已归入复制链1的弹幕，从下一条未归类的弹幕开始，重复上述过程
3. 最终得到若干条复制链
4. 复制率 = Σ(所有复制链的弹幕数) / 窗口总弹幕数
```

**参数**：
- 窗口 W = 15秒（刷队形通常发生在较短时间内）
- 最小链长 = 3条（过滤巧合相似）

**阈值与含义**：
| 复制率  | 含义                                   |
| ------- | -------------------------------------- |
| < 10%   | 正常讨论，各说各的                     |
| 10%-30% | 出现轻度队形，有集体行为苗头           |
| 30%-60% | 强烈队形，观众在积极参与集体仪式       |
| > 60%   | 高度统一狂欢，几乎所有人都在刷同一句话 |

**与指标5（发言集中度）的关键区分**：
- 集中度高 + 复制率低 = 少数人刷屏吵架（用户维度）
- 集中度低 + 复制率高 = 不同用户自发刷同一句话（内容维度），这才是真正的高潮仪式

### 指标13：对话网络密度

**所属维度**：互动与关系

**核心问题**：用户之间在互相说话吗？还是所有人都在单向对主播输出？

**定义**：时间窗口内，用户之间通过弹幕形成回复关系的紧密程度。

**第一步：构建回复关系**

弹幕B被判定为“回复”弹幕A，需同时满足：
```
条件1（时间邻近）：1秒 < B.timestamp - A.timestamp ≤ 15秒
条件2（内容关联），满足任一：
  a. B的文本包含A的用户名（@关系）
  b. A以问号结尾且B不是问句（问答模式）
  c. A和B共享至少一个非停用词且词长≥2（关键词重复）
  d. A和B的情感类别相同（情感呼应）
  e. B与A的文本相似度>0.7（队形跟随）
条件3：A和B来自不同用户ID
```

**第二步：计算网络密度**
```
V = 窗口内参与回复关系的用户集合（至少有一条回复边相连）
E = 检测到的回复边总数

网络密度 = |E| / (|V| × (|V|-1))
```
分母是有向完全图的最大边数。

**阈值与含义**：
| 网络密度  | 含义             | 典型场景                  |
| --------- | ---------------- | ------------------------- |
| < 0.05    | 极稀疏，各说各的 | 单向情绪输出（全员“666”） |
| 0.05-0.15 | 出现局部互动簇   | 正常弹幕互动              |
| 0.15-0.30 | 较密集互动       | 争议讨论、群体聊天        |
| > 0.30    | 高度互动         | 弹幕区激烈交流            |

**与指标5的联动矩阵**：
| 网络密度 | 发言集中度 | 场景                                     |
| -------- | ---------- | ---------------------------------------- |
| 低       | 低         | **广播模式**：所有人单向对主播输出       |
| 低       | 高         | **独角戏**：少数人刷屏无人回应           |
| 高       | 低         | **广场模式**：人人互相讨论               |
| 高       | 高         | **对峙模式**：少数人激烈争吵，其他人围观 |

### 指标14：观点极化度

**所属维度**：互动与关系

**核心问题**：观众情绪是一边倒，还是正反两派在对打？

**定义**：时间窗口内弹幕情感的正负对立程度。极化度越高，观众分裂越严重。

**计算步骤**：

**第一步：弹幕级情感三分类**
```
正向：命中惊叹、喜悦、悲伤/感动词库
负向：命中愤怒、节奏/指挥词库
中立：未命中以上任一词库，或同时命中正负两类词库
```
> 进阶方案：用大模型对弹幕逐条做情感分类，能处理反讽和复杂语气，但成本较高。

**第二步：计算极化度**
```
P_pos = 正向弹幕数 / 窗口总弹幕数
P_neg = 负向弹幕数 / 窗口总弹幕数

如果 P_pos + P_neg = 0：
    极化度 = 0
否则：
    极化度 = 1 - |P_pos - P_neg| / (P_pos + P_neg)
```

**阈值与含义**：
| 极化度  | 含义             | 典型场景                   |
| ------- | ---------------- | -------------------------- |
| < 0.2   | 高度统一         | 全员惊叹/全员愤怒/全员泪目 |
| 0.2-0.5 | 有分歧但主流占优 | 少数反对声音被淹没         |
| 0.5-0.8 | 明显对立         | 正反两派势均力敌           |
| > 0.8   | 极端对立         | 弹幕区完全撕裂，五五开互喷 |

**与指标17（衰减模式）的联动**：极化度极高的高潮，衰减半衰期通常也长——两边会反复拉锯，很难迅速平息。

### 指标15：意见领袖突现

**所属维度**：互动与关系

**核心问题**：谁引爆了讨论？那条关键弹幕说了什么？

**定义**：在时间窗口内突然成为互动中心、被大量其他用户回复或跟随的用户。一次大规模节奏往往由一条弹幕点燃。

**计算步骤**：

**第一步：计算被响应度**
```
对于窗口内每个用户u：
被响应度(u) = 窗口内以u的弹幕为目标形成回复边的弹幕数
（回复关系判定逻辑同指标13）
```

**第二步：计算突现值**
```
基线(u) = u在该窗口前10分钟内的平均被响应度（每窗口均值）
突现值(u) = 当前窗口被响应度(u) - 基线(u)
```
单独看被响应度绝对值不够——有些用户（如主播本人）长期被回复。突现值把“平时不受关注、此刻突然被围攻”的用户凸显出来。

**第三步：识别意见领袖**
```
同时满足：
条件1：突现值 > 3（比平时多了至少3条指向Ta的回复）
条件2：被响应度 > 窗口内所有用户被响应度的均值 + 1σ
条件3：该用户在当前窗口内至少发了一条弹幕（不是纯被@的潜水用户）
```

**意见领袖类型**：
| 其弹幕特征     | 角色类型     |
| -------------- | ------------ |
| 抛出观点或疑问 | 话题发起者   |
| 高情感密度     | 情绪引爆者   |
| 包含新信息     | 信息源       |
| 刷梗/造梗      | 梗文化创造者 |

**实战价值**：锁定意见领袖后，提取Ta在窗口前后1分钟内发的弹幕，大概率能找到那条“引爆弹幕”——它本身可能并不起眼，但被后续大量回复推成了互动中心。

### 指标16：高潮持续时间

**所属维度**：时间演化与价值

**核心问题**：热了多久？是昙花一现还是持续高能？

**定义**：从弹幕密度突破阈值到回落至阈值以下所持续的连续时间长度。

**计算步骤**：
```
1. 设定阈值：Threshold = μ_D + 2σ_D
2. 扫描整场密度曲线，找到所有 D(t) > Threshold 的连续区间
3. 每个区间：持续时间 = t_end - t_start
4. 如果两个区间之间的间隔 < 30秒，且用户重合度 > 50%，合并为一个高潮段
   （避免把一个完整事件的短暂回落误切为两段）
```

**形态分类**：
| 类型     | 持续时间 | 特征                                              |
| -------- | -------- | ------------------------------------------------- |
| 尖峰型   | < 60秒   | 瞬间爆发，迅速回落，典型于瞬发笑点或惊吓          |
| 短高潮   | 1-3分钟  | 一个完整小事件的讨论周期                          |
| 高原型   | 3-10分钟 | 持续高能，重大节奏或持续输出的名场面              |
| 超长高潮 | > 10分钟 | 可能不是单一高潮，建议结合指标6（用户重合度）切分 |

**注意事项**：阈值倍数可调。2σ是经验起点，如果检出太多碎片化尖峰，上调到2.5σ或3σ；如果几乎检不出高潮段，下调到1.5σ。户外直播的弹幕量方差通常大于游戏直播，可能需要分类设定阈值。

---

### 指标17：高潮衰减模式

**所属维度**：时间演化与价值

**核心问题**：观众是爽完就走，还是意犹未尽一直在回味？

**定义**：高潮结束后，弹幕密度从峰值回落到基线的方式和速度。

**计算步骤**：

**第一步：定位衰减起点与基线**
```
衰减起点 = 高潮区间内密度最大值的时间点
          （如果存在多个峰，取最后一个主峰顶点）
基线 = 高潮开始前30秒内的密度均值
```

**第二步：计算半衰期**
```
半衰期 = 密度从峰值下降到峰值50%所需的时间（秒）
```
- 短半衰期（<30秒）：指数级骤降，一次性情绪释放
- 长半衰期（>2分钟）：平缓回落，观众在持续讨论回味

**第三步：衰减曲线拟合**
```
对衰减区间的密度数据，分别拟合：
指数模型：D(t) = a × e^(-b×t)  → 爽完就走
对数模型：D(t) = a - b × ln(t)  → 意犹未尽

比较两者的R²，取拟合更优者为判定结果
```

**第四步：统计反弹次数**
```
衰减区间内，统计密度重新突破"峰值×50%"的次数
```

**衰减模式判定**：
| 模式   | 半衰期 | 拟合         | 反弹  | 场景                     |
| ------ | ------ | ------------ | ----- | ------------------------ |
| 骤降型 | <30秒  | 指数R²>0.8   | 0次   | 一次性情绪宣泄           |
| 缓降型 | >2分钟 | 对数R²更优   | 0-1次 | 讨论在慢慢发酵           |
| 反复型 | 不定   | 拟合效果都差 | ≥2次  | 事件被反复提起，连锁反应 |

### 指标18：用户留存转化

**所属维度**：时间演化与价值

**核心问题**：高潮有没有把人留下来？商业价值如何？

**定义**：在高潮时段被激活的用户（首次发言或长期沉默后回归），在后续时段是否继续参与。

**计算步骤**：

**第一步：定义转化目标人群**
```
转化目标用户 = 
  {在高潮时段首次发言的用户（整场新面孔）}
  ∪ {在高潮时段发言，且此前已连续沉默 > 30分钟的用户（被召回者）}

排除：直播前5分钟内发过言的用户不计入沉默池（还在“入场期”）
```

**第二步：跟踪留存**
```
留存_10min = 转化目标用户中，高潮结束后10分钟内至少发言1次的人数
留存_30min = 转化目标用户中，高潮结束后30分钟内至少发言1次的人数
留存_全程 = 转化目标用户中，高潮结束后任意时间至少发言1次的人数
```

**第三步：计算留存率**
```
10分钟留存率 = 留存_10min / 转化目标用户总数
30分钟留存率 = 留存_30min / 转化目标用户总数
全程留存率 = 留存_全程 / 转化目标用户总数
```

**阈值与含义**：
| 10分钟留存率 | 含义                                     |
| ------------ | ---------------------------------------- |
| > 40%        | 极强留存，高潮有粘性，用户被内容吸引留下 |
| 20%-40%      | 中等留存，正常水平                       |
| < 20%        | 低留存，围观路人看完热闹即走             |

**进阶——付费转化（如有数据）**：
```
付费转化密度 = 高潮时段付费用户数 / 高潮时段活跃用户总数
```
这个指标直接关联商业价值，是内容型高潮和变现型高潮的桥梁。

**注意事项**：高潮发生在直播尾声时（最后30分钟内），留存窗口不足，需要特殊标注并只计算到直播结束时的有限留存率。

### 指标19：事件关联引爆

**所属维度**：时间演化与价值

**核心问题**：有没有形成连环爆的节奏链？整场直播的节奏结构是怎样的？

**定义**：一个高潮事件在短时间内触发了另一个独立的高潮事件，形成“引爆链”。

**计算步骤**：

**第一步：切分独立事件**
```
独立事件 = 满足以下任一的高潮段：
  条件A：与前一个高潮段的用户重合度 < 30%（人群不同）
  条件B：与前一个高潮段的语义主题余弦相似度 < 0.3（内容不同）
```

**第二步：判定引爆关系**
```
事件A → 事件B 存在引爆关系，需同时满足：
  条件1：时间间隔 = B.start - A.end ∈ (0, 5分钟]
  条件2：A的沉默用户激活率 > 50%（A本身具有出圈效应）
  条件3（加分项）：B的转化目标用户中，>20%曾在A时段首次发言
          （A拉进来的新用户，在B时段继续活跃）
```

**第三步：构建引爆链**
```
- 0阶事件：无前序引爆，自发产生
- 1阶事件：由0阶事件引爆
- 2阶事件：由1阶事件引爆（连环爆第三环）
- 依此类推
```

**引爆模式分类**：
| 模式     | 特征                           | 典型场景                            |
| -------- | ------------------------------ | ----------------------------------- |
| 单次爆发 | 只有0阶事件，无后续引爆        | 一次性笑点/操作秀，炸完就散         |
| 线性连锁 | 0阶→1阶→2阶，事件依次传递      | 主播失误→弹幕群嘲→房管封人→更大节奏 |
| 星型引爆 | 一个0阶事件同时引爆多个1阶事件 | 重大爆料后引发多方向讨论            |

**可视化建议**：纵轴为时间，每个高潮事件为一个节点，节点大小正比于峰值密度，箭头表示引爆关系。这张图就是整场直播的“节奏心电图”，能直观判断直播内容的结构质量和情绪惯性维持能力。
